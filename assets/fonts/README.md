# Fonts Setup Instructions

## Bebas Neue Font

Download **BebasNeue-Regular.ttf** from:

1. Google Fonts: https://fonts.google.com/specimen/Bebas+Neue
2. Click "Download" → Select Regular (400) weight
3. Extract the TTF file and place it in this directory

The app's \_layout.tsx already references this font for the title and buttons.
