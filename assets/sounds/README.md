# Assets Setup Instructions

## Fonts

Download and place in this directory:

- **BebasNeue-Regular.ttf** from Google Fonts: https://fonts.google.com/specimen/Bebas+Neue

## Sounds

Add the following MP3 sound files to this directory (max 4 seconds each):

- **classic-tick.mp3** - Traditional chess clock tick sound
- **wood-knock.mp3** - Wooden knock sound
- **digital-beep.mp3** - Electronic beep sound
- **soft-bell.mp3** - Gentle bell sound

You can:

1. Download royalty-free sounds from sites like Freesound.org or Zapsplat.com
2. Use the provided example sounds if available
3. Generate custom sounds using audio editing software

Make sure all sounds are:

- In MP3 format
- Under 4 seconds in duration
- Optimized for file size
